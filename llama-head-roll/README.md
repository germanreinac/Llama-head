# Llama Head Roll

A one-file browser game. You are a llama's head, rolling down the altiplano ahead of a dust storm.

- **Roll** with ← → (or A / D). **Hop** with Space. P pauses, M mutes.
- On a phone, use the on-screen pads.
- Corn is worth 5 points. A chili gives four seconds of boost that smashes cacti.
- Three cactus hits, or the storm catching you, ends the run.

## Play

Open `index.html` in a browser. No install, no dependencies.

## Edit

The game lives in `game.html`. Run `./build.sh` to regenerate `index.html`.
